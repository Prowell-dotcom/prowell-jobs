How to add the extension to Chrome or Edge
  1. Download the ZIP, extract it, and keep the extracted folder on your computer.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode, select Load unpacked, and choose the folder containing manifest.json.
  4. Sign in to 4writers on its official website and open the extension to configure it.

Browsers do not allow websites to silently install unpacked extensions. You must approve installation yourself. Only use extensions whose code you trust.
